# wbipc-reward — WorkBuddy 每日积分自动任务

一行命令完成 WorkBuddy 每日积分三件事：**签到 → Buddy 旅行（派遣/领取/自动再派）→ 成长计划 7/14/28 天奖励自动领取**。专为配定时任务设计：幂等、防重、失败自愈、静默运行。

## 它解决的问题

WorkBuddy 桌面端 5.6.2 起，本地登录态改为加密存储（`$wbEncrypted`），"读本地登录态再调 API"的常规自动化路线全部失效。本工具换了一条路：**走桌面端的 wbipc 本机命名管道，让桌面端自己代为发起官方 HTTP 请求**——鉴权由桌面端注入，脚本全程不接触任何账号密码、Cookie 或令牌。

## 特性

- **幂等**：重复运行无副作用。已签到、当日额度用完、奖励已领，都返回正常状态而不是报错。
- **先查后领**：所有领取动作先查服务端状态，仅状态明确为可领才发一次请求；409 冲突不重试、403 未达标不重试，绝不重复领取。
- **日志短路**：配多条定时任务时，当日已全部办妥则后续运行读本地日志直接退出，**零网络请求**；当日有过失败则自动重走全流程（自愈）。
- **退出码语义化**：`0`=正常、`1`=有失败项、`2`=通道不可用——上层调度可靠判断。
- **自动再派**：Buddy 旅行到站领完奖，若当日额度没用完，自动再派一程，不浪费额度。
- **日志治理**：每次运行追加单行摘要到 `logs/result.log`，超 300KB 自动归档。
- **零依赖**：纯 Python 标准库，无需安装任何第三方包。

## 安装

1. 确认 WorkBuddy 桌面端已安装且登录；
2. 将本目录放到 `~/.workbuddy/skills/wbipc-reward/`（或任意位置，脚本不依赖固定路径）；
3. 试试第一条命令：

```bash
python scripts/reward.py status    # 只读体检，不签不领不派
```

## 用法

```bash
python scripts/reward.py                 # 默认：签到 + 旅行 + 成长计划自动领取
python scripts/reward.py status          # 只读：签到/旅行状态
python scripts/reward.py growth status   # 只读：成长计划三档状态与连登天数
python scripts/reward.py growth claim 7d    # 领取指定档（仅可领时发请求）
python scripts/reward.py growth claim-all   # 领取所有可领档位
```

输出为单行 JSON（字段见 `SKILL.md`），退出码见上。

## 配定时任务

两条路任选：

- **WorkBuddy 内建自动化**（推荐）：建一条每日循环自动化，执行默认命令即可；建议早中晚各一条兜底——日志短路会让多余的几次几乎零成本；
- **系统计划任务 / cron**：同样调默认命令，按退出码处理告警。

## 安全边界

- 脚本**不读取、不存储、不传输**任何账号凭据；鉴权完全由桌面端完成；
- 只访问 WorkBuddy 官方积分活动相关接口（签到/旅行/成长计划），清单见 `SKILL.md`；
- 所有请求发往你自己的桌面端通道，不出本机网络之外。
